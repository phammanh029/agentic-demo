# Workshop resources

This archive contains the Shop 6 `create-implementation-issue` and Spec Kit skills under `.agents/skills/`. Extract the archive at a repository root to use them with an agent that supports repository skills.

- **Superpowers** — agentic software-development skills and workflows: <https://github.com/obra/superpowers>
- **rtk** — CLI proxy that reduces noisy command output: <https://github.com/rtk-ai/rtk>
- **CodeGraph** — code-graph tools for call graphs and impact analysis: <https://github.com/codegraph-ai/CodeGraph>
- **GitHub Spec Kit** — toolkit for spec-driven development: <https://github.com/github/spec-kit>
- **GitHub Agentic Workflows** — repository for GitHub's agentic workflow tooling: <https://github.com/github/gh-aw>

The links point to upstream documentation and projects; this archive does not bundle their software. Check each project's current instructions before installing or using it.
